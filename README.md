# WikiRoll

A Discord bot for rolling, claiming, and trading characters pulled from Wikipedia and 150+ Fandom wikis.

🔗 **Live:** [wikiroll.hackatoa.com](https://wikiroll.hackatoa.com)   ·   ☕ **Support:** [Buy Me a Coffee](https://buymeacoffee.com/hackatoa)

## Overview

A gacha-style collection bot. Roll to summon characters sourced from Wikipedia and Fandom, claim your favorites, build a collection, trade with others, and climb the leaderboard.

## Features

- Roll / claim / collection / trade / wishlist / leaderboard
- Characters from Wikipedia and 150+ Fandom wikis
- Per-guild `/language` (6 languages)
- Slash-command and `w.<cmd>` prefix interfaces

## Tech Stack

Node.js · discord.js · better-sqlite3 · Docker

## Development

```bash
npm install
# set your Discord bot token in the environment, then:
npm start
```

## Deployment

Docker on the homelab host; GHCR + Watchtower auto-deploy.
