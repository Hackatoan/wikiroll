Datenschutz

Zuletzt aktualisiert: Juni 2026  ·  WikiRoll Discord Bot

WikiRoll erfasst nur die minimalen Daten, die zum Betrieb des Bots erforderlich sind. Wir verkaufen, teilen oder monetarisieren deine Daten in keiner Weise.

1. Welche Daten wir erfassen

WikiRoll speichert die folgenden Daten in einer lokalen SQLite-Datenbank auf unserem Server:

  • Discord-Benutzer-ID — um deinem Konto den Besitz von Charakteren, Wunschlisten und Abklingzeiten zuzuordnen
  • Discord-Server- (Gilde-)ID — zur Begrenzung von Besitzrechten und Einstellungen pro Server
  • Charakterdatensätze — Name, Quell-Wiki-URL, Vorschaubild-URL und Wikipedia-/Fandom-Seiten-ID
  • Besitzdatensätze — welcher Nutzer auf welchem Server welchen Charakter besitzt
  • Wunschlisteneinträge — Charakternamen oder Quellen, die du auf deine Wunschliste gesetzt hast
  • Roll-Abklingzeiten — Zeitstempel deines letzten Rolls pro Server
  • Von Nutzern eingereichte Bild-URLs — Discord-CDN-URLs, die du über /submitimage bereitstellst
  • Handelsaufzeichnungen — aktive und abgeschlossene Trades zwischen Nutzern

Wir nicht sammeln: Benutzernamen, E-Mail-Adressen, Nachrichteninhalt (abgesehen von Befehlsargumenten), IP-Adressen oder andere persönliche Informationen.

2. Wie wir sie verwenden

Alle gesammelten Daten werden ausschließlich zur Bereitstellung der Kernfunktionen des Bots verwendet:

  • Verfolgung des Charakterbesitzes in jedem Server
  • Durchsetzung von Roll-Abklingzeiten
  • Senden von DM-Benachrichtigungen, wenn auf der Wunschliste stehende Charaktere gerollt werden
  • Verarbeitung von Trades zwischen Nutzern

3. Datenspeicherung

Deine Daten werden so lange gespeichert, wie du den Bot nutzt. Du kannst:

  • Einzelne Charaktere aus deiner Sammlung mit /remove entfernen
  • Deine Wunschliste mit /wishlist remove leeren
  • Die vollständige Löschung deiner Daten beantragen, indem du ein GitHub Issue

Wenn der Bot von einem Server entfernt wird, können die Daten dieses Servers unbegrenzt in der Datenbank gespeichert bleiben. Server-Administratoren können uns kontaktieren, um die Löschung zu beantragen.

4. Datenweitergabe

Wir verkaufen, vermieten oder teilen deine Daten nicht mit Dritten. Der Bot ruft Charakterdaten von öffentlichen Wikipedia- und Fandom-APIs ab — deine Discord-Informationen werden niemals an diese Dienste gesendet.

5. Sicherheit

Daten werden in einer SQLite-Datenbank auf einem selbst gehosteten Server gespeichert. Der Zugriff ist auf den Serveradministrator beschränkt. Wir treffen angemessene Vorkehrungen, können jedoch keine absolute Sicherheit garantieren.

6. Kinder

WikiRoll sammelt wissentlich keine Daten von Benutzern unter 13 Jahren. Wenn du glaubst, dass ein Kind den Bot genutzt hat, kontaktiere uns bitte zur Datenlöschung.

7. Änderungen

Wir können diese Richtlinie von Zeit zu Zeit aktualisieren. Die fortgesetzte Nutzung des Bots nach Änderungen gilt als Annahme der neuen Richtlinie.

8. Kontakt

Für Datenschutzanfragen oder Fragen eröffne ein Problem auf github.com/Hackatoan/wikiroll/issues oder besuche hackatoa.com.
