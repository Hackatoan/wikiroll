Política de Privacidad

Última actualización: junio de 2026  ·  Bot de Discord de WikiRoll

WikiRoll recopila los datos mínimos necesarios para ejecutar el bot. No vendemos, compartimos ni monetizamos tus datos de ninguna manera.

1. Qué recopilamos

WikiRoll almacena los siguientes datos en una base de datos SQLite local en nuestro servidor:

  • ID de usuario de Discord — para asociar la propiedad de personajes, listas de deseos y tiempos de espera con tu cuenta
  • ID de servidor (gremio) de Discord — para delimitar la propiedad y la configuración por servidor
  • Registros de personajes — nombre, URL de la wiki de origen, URL de miniatura y ID de página de Wikipedia/Fandom
  • Registros de propiedad — qué usuario en qué servidor posee qué personaje
  • Entradas de la lista de deseos — nombres de personajes o fuentes que has añadido a tu lista de deseos
  • Tiempos de espera de tiradas — marca de tiempo de tu última tirada por servidor
  • URL de imágenes enviadas por usuarios — URL de CDN de Discord que proporcionas mediante /submitimage
  • Registros de intercambios — intercambios activos y completados entre usuarios

No recopilamos: nombres de usuario, direcciones de correo electrónico, contenido de mensajes (más allá de los argumentos de comandos), direcciones IP ni ninguna otra información personal.

2. Cómo lo usamos

Todos los datos recopilados se utilizan únicamente para el funcionamiento de las funciones principales del bot:

  • Rastrear la propiedad de personajes dentro de cada servidor
  • Aplicar los tiempos de espera de tiradas
  • Enviar notificaciones por mensaje directo cuando aparezca un personaje de la lista de deseos
  • Procesar intercambios entre usuarios

3. Retención de datos

Tus datos se conservan mientras uses el bot. Puedes:

  • Eliminar personajes individuales de tu colección con /remove
  • Borrar tu lista de deseos con /wishlist remove
  • Solicitar la eliminación completa de tus datos abriendo un GitHub Issue

Si se elimina el bot de un servidor, es posible que los datos de dicho servidor se conserven en la base de datos indefinidamente. Los administradores del servidor pueden ponerse en contacto con nosotros para solicitar su eliminación.

4. Compartir datos

No vendemos, alquilamos ni compartimos tus datos con terceros. El bot obtiene datos de personajes de las API públicas de Wikipedia y Fandom; tu información de Discord nunca se envía a dichos servicios.

5. Seguridad

Los datos se almacenan en una base de datos SQLite en un servidor propio. El acceso está restringido al administrador del servidor. Tomamos precauciones razonables, pero no podemos garantizar una seguridad absoluta.

6. Menores

WikiRoll no recopila conscientemente datos de usuarios menores de 13 años. Si crees que un menor ha utilizado el bot, ponte en contacto con nosotros para eliminar sus datos.

7. Cambios

Podemos actualizar esta política de vez en cuando. El uso continuado del bot después de los cambios constituye la aceptación de la nueva política.

8. Contacto

Para solicitudes de privacidad o preguntas, abre una incidencia en github.com/Hackatoan/wikiroll/issues o visita hackatoa.com.
