Política de Privacidade

Última atualização: junho de 2026  ·  Discord Bot do WikiRoll

O WikiRoll coleta o mínimo de dados necessários para executar o bot. Nós não vendemos, compartilhamos ou monetizamos os seus dados de nenhuma forma.

1. O Que Coletamos

O WikiRoll armazena os seguintes dados em um banco de dados SQLite local em nosso servidor:

  • ID de Usuário do Discord — para associar a posse de personagens, listas de desejos e tempos de espera (cooldowns) à sua conta
  • ID do Servidor (Guilda) do Discord — para delimitar a propriedade e as configurações por servidor
  • Registros de personagens — nome, URL da wiki de origem, URL da miniatura e ID da página na Wikipedia/Fandom
  • Registros de propriedade — qual usuário em qual servidor possui qual personagem
  • Entradas da lista de desejos — nomes de personagens ou origens que você adicionou à lista de desejos
  • Tempos de espera dos rolls — carimbo de data/hora do seu último roll por servidor
  • URLs de imagens enviadas por usuários — URLs da CDN do Discord fornecidas por você via /submitimage
  • Registros de trocas — trocas ativas e concluídas entre usuários

Nós não coletamos: nomes de usuário, endereços de e-mail, conteúdo de mensagens (além dos argumentos de comandos), endereços IP ou qualquer outra informação pessoal.

2. Como Nós Usamos

Todos os dados coletados são usados exclusivamente para operar os recursos principais do bot:

  • Rastrear a posse de personagens dentro de cada servidor
  • Aplicar tempos de espera (cooldowns) de rolagens
  • Enviar notificações por DM quando personagens da lista de desejos (wishlist) forem rolagens
  • Processar trocas entre usuários

3. Retenção de Dados

Seus dados são retidos enquanto você usar o bot. Você pode:

  • Remover personagens individuais da sua coleção com /remove
  • Limpar sua lista de desejos com /wishlist remove
  • Solicitar a exclusão completa dos seus dados abrindo uma GitHub Issue

Se o bot for removido de um servidor, os dados desse servidor poderão ser mantidos no banco de dados indefinidamente. Administradores de servidores podem entrar em contato conosco para solicitar a exclusão.

4. Compartilhamento de Dados

Não vendemos, alugamos ou compartilhamos seus dados com terceiros. O bot busca dados de personagens em APIs públicas da Wikipedia e do Fandom — suas informações do Discord nunca são enviadas para esses serviços.

5. Segurança

Os dados são armazenados em um banco de dados SQLite em um servidor próprio. O acesso é restrito ao administrador do servidor. Tomamos precauções razoáveis, mas não podemos garantir segurança absoluta.

6. Crianças

O WikiRoll não coleta conscientemente dados de usuários com menos de 13 anos. Se você acredita que uma criança usou o bot, entre em contato conosco para a remoção dos dados.

7. Alterações

Podemos atualizar esta política periodicamente. O uso continuado do bot após as alterações constitui aceitação da nova política.

8. Contato

Para solicitações de privacidade ou dúvidas, abra uma issue em github.com/Hackatoan/wikiroll/issues ou visite hackatoa.com.
