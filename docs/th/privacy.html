นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: มิถุนายน 2026  ·  บอท Discord WikiRoll

WikiRoll รวบรวมข้อมูลเพียงเล็กน้อยที่สุดเท่าที่จำเป็นเพื่อเรียกใช้งานบอท เราไม่ขาย แบ่งปัน หรือสร้างรายได้จากข้อมูลของคุณไม่ว่าด้วยวิธีใดก็ตาม

1. สิ่งที่เราเก็บรวบรวม

WikiRoll จัดเก็บข้อมูลต่อไปนี้ลงในฐานข้อมูล SQLite แบบローカルในเซิร์ฟเวอร์ของเรา:

  • Discord User ID — เพื่อเชื่อมโยงการเป็นเจ้าของตัวละคร รายการที่อยากได้ และคูลดาวน์เข้ากับบัญชีของคุณ
  • ID เซิร์ฟเวอร์ Discord (กิลด์) — เพื่อจำกัดขอบเขตความเป็นเจ้าของและการตั้งค่าต่อเซิร์ฟเวอร์
  • บันทึกข้อมูลตัวละคร — ชื่อ, URL วิกิแหล่งที่มา, URL ภาพย่อ และ ID หน้า Wikipedia/Fandom
  • บันทึกความเป็นเจ้าของ — ผู้ใช้คนใดในเซิร์ฟเวอร์ใดที่เป็นเจ้าของตัวละครใด
  • รายการสิ่งที่อยากได้ — ชื่อตัวละครหรือแหล่งที่มาที่คุณใส่ไว้ในรายการสิ่งที่อยากได้
  • คูลดาวน์การสุ่ม — แสตมป์เวลาของการสุ่มครั้งล่าสุดของคุณต่อเซิร์ฟเวอร์
  • URL รูปภาพที่ผู้ใช้ส่ง — URL ของ Discord CDN ที่คุณระบุผ่าน /submitimage
  • บันทึกการแลกเปลี่ยน — การแลกเปลี่ยนที่ใช้งานอยู่และเสร็จสิ้นระหว่างผู้ใช้

เราไม่เก็บรวบรวม: ชื่อผู้ใช้, ที่อยู่อีเมล, เนื้อหาข้อความ (นอกเหนือจากอาร์กิวเมนต์คำสั่ง), ที่อยู่ IP หรือข้อมูลส่วนบุคคลอื่นใด

2. วิธีที่เราใช้ข้อมูล

ข้อมูลทั้งหมดที่รวบรวมจะถูกใช้เพื่อ1ดำเนินฟีเจอร์หลักของบอทเท่านั้น:

  • ติดตามความเป็นเจ้าของตัวละครภายในแต่ละเซิร์ฟเวอร์
  • บังคับใช้คูลดาวน์การสุ่ม
  • ส่งการแจ้งเตือนทาง DM เมื่อสุ่มได้ตัวละครที่อยู่ในรายการสิ่งที่อยากได้
  • ดำเนินการแลกเปลี่ยนระหว่างผู้ใช้

3. การเก็บรักษาข้อมูล

ข้อมูลของคุณจะถูกเก็บไว้ตราบเท่าที่คุณใช้งานบอท คุณสามารถ:

  • ลบตัวละครแต่ละตัวออกจากคอลเลกชันของคุณด้วย /remove
  • ล้างรายการที่อยากได้ของคุณด้วย /wishlist remove
  • ขอให้ลบข้อมูลของคุณทั้งหมดโดยการเปิด GitHub Issue

หากบอทถูกนำออกจากเซิร์ฟเวอร์ ข้อมูลของเซิร์ฟเวอร์นั้นอาจถูกเก็บไว้ในฐานข้อมูลอย่างไม่มีกำหนด แอดมินเซิร์ฟเวอร์สามารถติดต่อเราเพื่อขอให้ลบข้อมูลได้

4. การแบ่งปันข้อมูล

เราไม่ขาย ให้เช่า หรือแบ่งปันข้อมูลของคุณกับบุคคลที่สาม บอทจะดึงข้อมูลตัวละครจาก API สาธารณะของ Wikipedia และ Fandom — ข้อมูล Discord ของคุณจะไม่ถูกส่งไปยังบริการเหล่านั้นอย่างเด็ดขาด

5. ความปลอดภัย

ข้อมูลถูกจัดเก็บไว้ในฐานข้อมูล SQLite บนเซิร์ฟเวอร์ที่โฮสต์เอง การเข้าถึงจำกัดเฉพาะผู้ดูแลระบบเซิร์ฟเวอร์เท่านั้น เราใช้มาตรการป้องกันที่สมเหตุสมผลแต่ไม่สามารถรับประกันความปลอดภัยสูงสุดได้

6. เด็ก

WikiRoll จะไม่เก็บรวบรวมข้อมูลจากผู้ใช้ที่มีอายุต่ำกว่า 13 ปีโดยเจตนา หากคุณเชื่อว่าเด็กได้ใช้งานบอท โปรดติดต่อเราเพื่อลบข้อมูล

7. การเปลี่ยนแปลง

เราอาจปรับปรุงนโยบายนี้เป็นครั้งคราว การใช้งานบอทอย่างต่อเนื่องหลังจากมีการเปลี่ยนแปลงจะถือเป็นการยอมรับนโยบายใหม่

8. ติดต่อ

หากมีคำขอหรือคำถามเกี่ยวกับความเป็นส่วนตัว โปรดเปิดปัญหาที่ github.com/Hackatoan/wikiroll/issues หรือไปที่ hackatoa.com.
