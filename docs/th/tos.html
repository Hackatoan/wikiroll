ข้อกำหนดในการให้บริการ

อัปเดตล่าสุด: มิถุนายน 2026  ·  WikiRoll Discord Bot

1. การยอมรับ

โดยการเพิ่ม WikiRoll ลงในเซิร์ฟเวอร์ Discord ของคุณหรือใช้คำสั่งใดๆ ของบอท ถือว่าคุณยอมรับข้อกำหนดในการให้บริการเหล่านี้ หากคุณไม่ยอมรับ โปรดลบ bot ออกจากเซิร์ฟเวอร์ของคุณ

2. คำอธิบายบริการ

WikiRoll เป็น Discord bot ฟรีที่ให้ผู้ใช้สามารถสุ่ม (roll) เคลม และแลกเปลี่ยนตัวละครที่มาจาก Wikipedia และ Fandom wiki ของบุคคลที่สาม ข้อมูลตัวละครทั้งหมดดึงมาจาก API ของ wiki ที่เปิด  sสาธารณะและเป็นของ wiki และผู้มีส่วนร่วมนั้นๆ

3. การใช้งานที่ยอมรับได้

คุณตกลงที่จะไม่:

  • ใช้บอทเพื่อสแปม กลั่นแกล้ง หรือละเมิดผู้ใช้รายอื่น
  • พยายามหาประโยชน์ วิศวกรรมย้อนกลับ หรือขัดขวางการทำงานของบอท
  • ส่ง URL รูปภาพหรือเนื้อหาที่เป็นอันตราย
  • ใช้บอทโดยละเมิดข้อกำหนดของ Discord ข้อกำหนดในการให้บริการ

4. ข้อมูล

WikiRoll จะจัดเก็บข้อมูลขั้นต่ำที่จำเป็นสำหรับการทำงาน ได้แก่ ID ผู้ใช้ Discord, ID เซิร์ฟเวอร์ (กิลด์), บันทึกความเป็นเจ้าของตัวละคร, รายการที่ต้องการ (wishlist) และ URL รูปภาพที่ผู้ใช้ส่งเข้ามา จะไม่มีการรวบรวมข้อมูลส่วนบุคคลใดๆ นอกเหนือจากที่ Discord มีให้ โปรดดูรายละเอียดเพิ่มเติมได้ที่ นโยบายความเป็นส่วนตัว ของเรา

5. เนื้อหา

ข้อมูลตัวละครดึงมาจากวิกิของ Wikipedia และ Fandom ภายใต้ใบอนุญาตที่เกี่ยวข้อง (CC-BY-SA และอื่นๆ) WikiRoll มิได้อ้างสิทธิ์ความเป็นเจ้าของในเนื้อหาวิกิใดๆ URL รูปภาพที่ผู้ใช้ส่งเข้ามาจะต้องลิงก์ไปยังเนื้อหาบน CDN ของ Discord และต้องไม่มีสิ่งผิดกฎหมายหรือเป็นอันตราย

6. ความพร้อมใช้งาน

WikiRoll เปิดให้บริการฟรีโดยไม่มีค่าใช้จ่ายตามความเหมาะสมที่ดีที่สุด เราไม่รับประกันเวลาทำงาน ความพร้อมใช้งาน หรือการจัดเก็บข้อมูล บริการอาจมีการเปลี่ยนแปลง ระงับ หรือยุติลงได้ตลอดเวลาโดยไม่ต้องแจ้งให้ทราบ

7. ผู้ดูแลเซิร์ฟเวอร์

ผู้ดูแลเซิร์ฟเวอร์มีหน้าที่รับผิดชอบต่อการใช้งานบอทภายในเซิร์ฟเวอร์ของตนเอง ผู้ดูแลสามารถกำหนดค่าคูลดาวน์ ลบตัวละคร และจำกัดการใช้งานได้ผ่านคำสั่ง /settings

8. การยุติการให้บริการ

เราขอสงวนสิทธิ์ในการบล็อกผู้ใช้หรือเซิร์ฟเวอร์ใด ๆ จากการใช้งาน WikiRoll ตามดุลยพินิจของเราแต่เพียงผู้เดียว โดยเฉพาะอย่างยิ่งในกรณีที่มีการละเมิดหรือฝ่าฝืนข้อกำหนดเหล่านี้

9. ข้อจำกัดความรับผิดชอบ

WikiRoll มีให้บริการ "ตามสภาพ" โดยไม่มีการรับประกันใด ๆ ทั้งสิ้น เราจะไม่รับผิดชอบต่อการสูญหายของข้อมูล การหยุดชะงักของบริการ หรือความเสียหายใด ๆ ที่เกิดขึ้นจากการใช้งานบอท
